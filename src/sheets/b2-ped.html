พฤติกรรมเพิ่ม = เสริมแรงเสริมแรงบวก: ติดดาวเมื่อส่งงานตรงเวลาเสริมแรงลบ: เลิกบ่นเมื่อนักเรียนทำการบ้านเสร็จ (เอาสิ่งที่ไม่ชอบออก)
พฤติกรรมลด = ลงโทษลงโทษบวก: ให้เขียนซ้ำ 100 รอบลงโทษลบ: ยึดสิทธิ์ใช้โทรศัพท์

ข้อสอบชอบพลิกตรงนี้

  • บวก/ลบ = ใส่เข้า/เอาออก · เสริมแรง/ลงโทษ = พฤติกรรมเพิ่ม/ลด · "เสริมแรงลบ" ไม่ใช่การลงโทษ (พฤติกรรมเพิ่ม)
  • Pavlov ดูสิ่งเร้าก่อนพฤติกรรม (ปฏิกิริยาอัตโนมัติ) · Skinner ดูผลที่ตามมาหลังพฤติกรรม (พฤติกรรมที่เลือกทำ)
  • การรักษาสภาพ (conservation) อยู่ขั้น Concrete operational ไม่ใช่ Preoperational · Piaget เน้นเด็กสร้างความรู้เอง · Vygotsky เน้นสังคมและผู้ช่วยเหลือ (ZPD)
  • Kohlberg วัด "เหตุผลที่ใช้ตัดสิน" ไม่ใช่ว่าทำดีหรือไม่ · Maslow ขั้นล่างยังขาดอยู่ ขั้นบนจะยังไม่เป็นแรงจูงใจหลัก
ตัวอย่างโจทย์พลิก: ครูให้นักเรียนที่ไม่ขาดเรียนทั้งเดือนไม่ต้องทำใบงานท้ายคาบ ทำให้นักเรียนมาเรียนสม่ำเสมอขึ้น เป็นการใดตามแนว Skinner
วิธีตัด: พฤติกรรม (มาเรียน) เพิ่ม → เป็น "เสริมแรง" ตัดการลงโทษ · สิ่งที่ถูกเอาออกคือใบงาน → "ลบ" → ตอบ เสริมแรงลบ

3. การแนะแนวและระบบดูแลช่วยเหลือนักเรียน

ต้องจำ

  • การแนะแนว 3 ด้าน: การศึกษา · อาชีพ · ส่วนตัวและสังคม
  • บริการแนะแนว 5 บริการ: (1) สำรวจ/รวบรวมข้อมูลนักเรียนเป็นรายบุคคล (individual inventory) → (2) สนเทศ → (3) ให้คำปรึกษา → (4) จัดวางตัวบุคคล → (5) ติดตามผล
  • ระบบดูแลช่วยเหลือนักเรียน 5 ขั้น: รู้จักนักเรียนเป็นรายบุคคล → คัดกรอง → ส่งเสริมนักเรียน → ป้องกันและแก้ไขปัญหา → ส่งต่อ
  • คัดกรองแบ่ง 3 กลุ่ม: ปกติ · เสี่ยง · มีปัญหา
  • เครื่องมือ: เยี่ยมบ้าน · ระเบียนสะสม · แบบประเมิน SDQ (พฤติกรรม อารมณ์) · สังคมมิติ (sociogram ดูความสัมพันธ์ในกลุ่ม หาผู้ที่ถูกเลือกมาก/ถูกโดดเดี่ยว) · กรณีศึกษา · การสังเกต

ข้อสอบชอบพลิกตรงนี้

  • ลำดับ: ต้องรู้จักก่อน คัดกรองก่อน จึงส่งเสริม/แก้ไข · "ส่งต่อ" เป็นขั้นสุดท้าย (ส่งต่อภายในหรือภายนอกเมื่อเกินความสามารถ)
  • สังคมมิติใช้ดูความสัมพันธ์ ไม่ใช่วัดสติปัญญาหรือบุคลิกภาพ · SDQ ใช้คัดกรองพฤติกรรม/อารมณ์ ไม่ใช่วัดความฉลาด
  • ครูที่ปรึกษาทำหน้าที่ "ให้คำปรึกษา" ไม่ใช่ตัดสินใจแทนนักเรียน
ตัวอย่างโจทย์พลิก: ครูให้นักเรียนเขียนชื่อเพื่อนที่อยากทำงานด้วย 3 คน แล้วนำมาเขียนแผนภาพความสัมพันธ์ เป็นเครื่องมือใด
วิธีตัด: ดูความสัมพันธ์ในกลุ่ม → สังคมมิติ (ตัด SDQ ซึ่งเป็นแบบประเมินพฤติกรรม และการเยี่ยมบ้านซึ่งไปดูครอบครัว)

วิธีตัด: คำขึ้นต้น "ความสามารถใน…" = สมรรถนะ ส่วน "ใฝ่เรียนรู้" อยู่ใน 8 คุณลักษณะ

6. Bloom ฉบับปรับปรุงและจุดประสงค์การเรียนรู้

ต้องจำ

ระดับ (ต่ำ → สูง)กริยาตัวอย่าง
1 จำ (Remember)บอก ระบุ ท่อง จำได้
2 เข้าใจ (Understand)อธิบาย สรุป ยกตัวอย่าง จัดประเภท
3 ประยุกต์/นำไปใช้ (Apply)คำนวณ แก้โจทย์ ใช้ ทดลอง
4 วิเคราะห์ (Analyze)จำแนก แยกองค์ประกอบ หาความสัมพันธ์
5 ประเมินค่า (Evaluate)ตัดสิน วิพากษ์ ให้เหตุผลเลือก
6 สร้างสรรค์ (Create)ออกแบบ วางแผน ประพันธ์ สร้าง
  • ฉบับเดิม (1956) คือ ความรู้ความจำ · ความเข้าใจ · การนำไปใช้ · การวิเคราะห์ · การสังเคราะห์ · การประเมินค่า · ฉบับปรับปรุง (2001) เปลี่ยนเป็นคำกริยา สลับให้ Create อยู่สูงสุด และ Evaluate เป็นขั้น 5
  • มิติความรู้ 4 แบบ: ข้อเท็จจริง · มโนทัศน์ · กระบวนวิธี · อภิปัญญา (metacognitive)
  • 3 พิสัย: พุทธิพิสัย (K ความรู้) · ทักษะพิสัย (P ทักษะ) · จิตพิสัย (A เจตคติ) · จิตพิสัย 5 ขั้น: รับรู้ → ตอบสนอง → เห็นคุณค่า → จัดระบบ → สร้างลักษณะนิสัย
  • จุดประสงค์เชิงพฤติกรรมต้องสังเกตและวัดได้: ใช้ "บอก อธิบาย คำนวณ" ไม่ใช้ "รู้ เข้าใจ ซาบซึ้ง ตระหนัก" · องค์ประกอบ: พฤติกรรม + เงื่อนไข + เกณฑ์

ข้อสอบชอบพลิกตรงนี้

  • สลับตำแหน่ง Synthesis/Create กับ Evaluate: ในฉบับปรับปรุง Create สูงสุด
  • "เปรียบเทียบ" คาบเกี่ยว: ถ้าให้แยกองค์ประกอบ/หาความสัมพันธ์ = วิเคราะห์ · ถ้าบอกความเหมือนต่างทั่วไป = เข้าใจ (ดูบริบทโจทย์)
  • ตัวเลือกที่ขึ้นต้น "เข้าใจ/ตระหนัก/รู้" ไม่ใช่จุดประสงค์เชิงพฤติกรรม
ตัวอย่างโจทย์พลิก: จุดประสงค์ "ออกแบบแผนผังการทำงานของระบบรดน้ำอัตโนมัติ" อยู่ระดับใดของ Bloom ฉบับปรับปรุง
วิธีตัด: กริยา "ออกแบบ" = สร้างสรรค์ (Create) ระดับสูงสุด · อย่าตอบ "ประยุกต์" เพียงเพราะเป็นงานปฏิบัติ

7. การวัดและประเมินผล

ต้องจำ

คำความหมาย
Diagnostic / Placementก่อนเรียน: หาจุดแข็งจุดอ่อน/ความพร้อม หรือจัดระดับ
Formativeระหว่างเรียน เพื่อปรับการสอน (ไม่ใช่เพื่อตัดสินผลสุดท้าย)
Summativeหลังจบหน่วย/ภาค เพื่อสรุปผลและตัดเกรด
Norm-referenced / Criterion-referencedเทียบกับกลุ่ม / เทียบกับเกณฑ์ที่กำหนดไว้
ความตรง (Validity)วัดได้ตรงสิ่งที่ต้องการวัด · ตรวจความตรงเชิงเนื้อหาด้วย IOC
ความเที่ยง (Reliability)วัดซ้ำได้ผลคงที่ · วิธี: test-retest, แบบคู่ขนาน, แบ่งครึ่ง, KR-20, Cronbach alpha
RubricHolistic ให้คะแนนภาพรวมรวบเดียว · Analytic แยกเกณฑ์ย่อยทีละด้าน (ให้ข้อมูลย้อนกลับละเอียดกว่า)
ประเมินตามสภาพจริงปฏิบัติจริง แฟ้มสะสมผลงาน (portfolio) ชิ้นงาน
  • ค่าความยากง่าย p = (H + L) / (2n) · ค่าอำนาจจำแนก r = (H − L) / n · H, L = จำนวนคนตอบถูกกลุ่มสูง/กลุ่มต่ำ · n = จำนวนคนในแต่ละกลุ่ม (ปกติ 27%) · เกณฑ์ที่ใช้บ่อย: p = 0.20–0.80 · r ≥ 0.20
  • IOC = ΣR / N (R = +1 สอดคล้อง, 0 ไม่แน่ใจ, −1 ไม่สอดคล้อง) · ใช้ได้เมื่อ ≥ 0.50
  • KR-20: r = [k/(k−1)] × [1 − Σpq/s²] · ค่าความเชื่อมั่นตั้งแต่ 0.70 ขึ้นไปถือว่ายอมรับได้ในตำราส่วนใหญ่
  • คะแนนมาตรฐาน: z = (X − เฉลี่ย)/S.D. · T = 50 + 10z
  • ระดับผลการเรียน 8 ระดับ: 80–100 = 4 · 75–79 = 3.5 · 70–74 = 3 · 65–69 = 2.5 · 60–64 = 2 · 55–59 = 1.5 · 50–54 = 1 · 0–49 = 0 · สัญลักษณ์: ร = รอการตัดสิน · มส = ไม่มีสิทธิ์เข้ารับการประเมิน · ผ = ผ่าน · มผ = ไม่ผ่าน

ตัวอย่างคำนวณที่ตรวจแล้ว: ผู้สอบ 100 คน กลุ่มสูง/ต่ำกลุ่มละ 27 คน ตอบถูก 20 และ 8 → p = 28/54 = 0.52 · r = 12/27 = 0.44 (ผ่านทั้งสองเกณฑ์) · ผู้เชี่ยวชาญ 5 คนให้ +1, +1, 0, +1, −1 → IOC = 2/5 = 0.40 (ต่ำกว่า 0.50 ต้องปรับหรือตัดข้อ) · คะแนน 70 เฉลี่ย 60 S.D. 5 → z = 2, T = 70

ข้อสอบชอบพลิกตรงนี้

  • เที่ยงไม่ได้แปลว่าตรง (ตาชั่งที่ผิดค่าคงที่เที่ยงแต่ไม่ตรง) แต่ถ้าไม่เที่ยงก็ไม่มีทางตรง
  • Formative (ระหว่างเรียน เพื่อปรับ) กับ Summative (ตอนจบ เพื่อสรุป) สลับกันบ่อย · Diagnostic เกิดก่อนเรียน
  • r ใช้ H − L หารด้วย n (ไม่ใช่ 2n) · p ใช้ H + L หารด้วย 2n · อย่าสลับสูตร
  • เกรด "ร" ไม่ใช่ "มส": ร = ยังไม่สมบูรณ์รอตัดสิน · มส = เวลาเรียนไม่ถึง 80%
ตัวอย่างโจทย์พลิก: ข้อสอบข้อหนึ่งกลุ่มสูง 27 คน ตอบถูก 20 กลุ่มต่ำ 27 คน ตอบถูก 8 ค่า p และ r เป็นเท่าใด
วิธีตัด: p = (20+8)/54 = 0.52 ใช้ได้ (อยู่ในช่วง 0.20–0.80) · r = (20−8)/27 = 0.44 ใช้ได้ (≥ 0.20) · ตัดตัวเลือกที่หารด้วย 27 สำหรับ p ออก

8. วิจัยในชั้นเรียน

ต้องจำ

  • ตัวแปรต้น = สิ่งที่ผู้วิจัยจัดกระทำ (เช่น วิธีสอนแบบใหม่) · ตัวแปรตาม = ผลที่วัด (เช่น ผลสัมฤทธิ์) · ตัวแปรควบคุม = สิ่งที่ต้องคงเดิม (เวลา ผู้สอน เนื้อหา)
  • สมมติฐานว่าง H₀ = ไม่แตกต่าง · สมมติฐานทางเลือก H₁ = แตกต่าง/สูงกว่า · ระบุทิศทาง ("สูงกว่า") หรือไม่ระบุทิศทาง ("แตกต่าง")
  • การวิจัยปฏิบัติการ วงจร PAOR: Plan วางแผน → Act ปฏิบัติ → Observe สังเกต → Reflect สะท้อนผล · ผลใช้อธิบายห้องของตน ไม่อ้างอิงไปยังประชากร
  • แบบแผน: กลุ่มเดียวสอบก่อน-หลัง (O₁ X O₂) · สองกลุ่มเปรียบเทียบ · t-test แบบคู่ (dependent) เมื่อกลุ่มเดียวก่อน-หลัง · t-test แบบอิสระ (independent) เมื่อสองกลุ่มต่างคน
  • การสุ่ม: แบบง่าย · เป็นระบบ · แบ่งชั้น · แบ่งกลุ่ม · (ไม่สุ่ม: เจาะจง สะดวก)
  • รายงานวิจัย 5 บท: บทนำ → เอกสารที่เกี่ยวข้อง → วิธีดำเนินการ → ผลการวิเคราะห์ → สรุป อภิปราย ข้อเสนอแนะ
  • E₁/E₂: E₁ = (ΣX/N)/A × 100 (A = คะแนนเต็มระหว่างเรียน) · E₂ = (ΣF/N)/B × 100 (B = คะแนนเต็มหลังเรียน) · เกณฑ์ 80/80 (ตำราไทยทั่วไปยอมให้ต่ำกว่าเกณฑ์ได้ไม่เกิน 2.5)
  • E.I. = (ΣPost − ΣPre) / [(คะแนนเต็ม × N) − ΣPre] · ใช้ได้เมื่อ ≥ 0.50
  • ตัวอย่างที่ตรวจแล้ว: N = 5, ระหว่างเรียน (เต็ม 20) รวม 82 → E₁ = 16.4/20 = 82.0 · หลังเรียน (เต็ม 30) รวม 126 → E₂ = 25.2/30 = 84.0 · ก่อนเรียนรวม 50 → E.I. = (126−50)/(150−50) = 0.76

ข้อสอบชอบพลิกตรงนี้

  • E₁ = ประสิทธิภาพกระบวนการ (ระหว่างเรียน) · E₂ = ประสิทธิภาพผลลัพธ์ (หลังเรียน) — ห้ามสลับ · ตัวส่วนของ E.I. ใช้ "เต็มรวมทุกคน − ก่อนเรียนรวม" ไม่ใช่คะแนนเต็มเดี่ยว
  • วิธีสอน = ตัวแปรต้น · ผลสัมฤทธิ์ = ตัวแปรตาม (สลับกันบ่อย)
  • เกณฑ์แปลผลค่าเฉลี่ย 5 ระดับมี 2 แบบในไทย (ช่วงละ 0.80: 1.00–1.80 / 1.81–2.60 / 2.61–3.40 / 3.41–4.20 / 4.21–5.00 หรือแบบ 4.51–5.00 / 3.51–4.50 / …) ผลต่างกันได้ จึงต้องใช้เกณฑ์ที่โจทย์ให้
ตัวอย่างโจทย์พลิก: ครูให้นักเรียนกลุ่มเดียวทำแบบทดสอบก่อนและหลังใช้สื่อ ควรเปรียบเทียบคะแนนด้วยสถิติใด
วิธีตัด: กลุ่มเดียวคนเดิม → t-test แบบคู่ (dependent) ตัด t-test แบบอิสระ ซึ่งใช้กับสองกลุ่มต่างคน
ข้อคู่: ค่าเฉลี่ย 4.25 ตามเกณฑ์ช่วง 0.80 = มากที่สุด แต่ตามเกณฑ์ 4.51–5.00 = มาก → ต้องดูเกณฑ์ในโจทย์

9. ประกันคุณภาพการศึกษาและ PLC

ต้องจำ

  • มาตรฐานการศึกษาขั้นพื้นฐาน (ฉบับ พ.ศ. 2561) มี 3 มาตรฐาน: (1) คุณภาพของผู้เรียน (2) กระบวนการบริหารและการจัดการ (3) กระบวนการจัดการเรียนการสอนที่เน้นผู้เรียนเป็นสำคัญ · ตรวจฉบับล่าสุดที่ moe.go.th / obec.go.th
  • SAR = รายงานผลการประเมินตนเอง (Self-Assessment Report) ของสถานศึกษา จัดทำทุกปี เสนอต้นสังกัดและเปิดเผยสาธารณะ
  • ประกันคุณภาพภายใน: สถานศึกษา/ต้นสังกัดทำเองอย่างต่อเนื่อง · ภายนอก: สมศ. ประเมินอย่างน้อยทุก 5 ปี (รายละเอียดดูชีทกฎหมาย)
  • PDCA: Plan วางแผน → Do ปฏิบัติ → Check ตรวจสอบ → Act ปรับปรุงแก้ไข (วงจรเดมมิง)
  • PLC (ชุมชนแห่งการเรียนรู้ทางวิชาชีพ): ครูรวมกลุ่มแลกเปลี่ยน สะท้อนผล พัฒนาการสอนร่วมกันเพื่อผลลัพธ์ของผู้เรียน · กิจกรรมที่ใช้: Lesson Study (Plan–Do–See) และ Open Class

  • PDCA ตัวที่ 4 คือ Act (ปรับปรุงแก้ไข) ไม่ใช่ Action หรือ Assess · "Check" มาก่อน "Act"
